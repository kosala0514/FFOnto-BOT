Introduction back to ToC

The danger rules of FFOnto are stored as data: each rule is an individual of ffonto:DangerRule with an observed property, an operator, a threshold value and the condition it indicates (a concept in the vocabulary). A SPARQL rule compares every weather / FWI record with these thresholds and derives ffonto:hasCondition, so a threshold can be changed and cited in one place without editing any query.

Note: the threshold values in version {{VERSION}} are placeholders for testing. They will be replaced by values from published fire-danger classifications, each with its source.
