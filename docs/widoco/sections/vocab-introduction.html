Introduction back to ToC

This is the controlled vocabulary of FFOnto. It holds the fine-grained kinds and values used in forest-fire knowledge graphs as SKOS concepts, organised in concept schemes and hierarchies (skos:broader). The core schema refers to them with generic properties such as ffonto:hasKind, ffonto:wears, ffonto:hasState and ffonto:hasHazardType, so new kinds can be added here without changing the schema.

  • skos:prefLabel is the display name; skos:hiddenLabel holds keywords used to tag captions and to constrain the vision-language model that extracts scene graphs.
  • Some concepts carry background knowledge used by the competency questions, e.g. ffonto:mitigatedBy (hazard → action), ffonto:requiredPPE, ffonto:typicalFireImpact and ffonto:suggestedRestoration.

The vocabulary has {{N_CONCEPTS}} concepts in {{N_SCHEMES}} schemes. The browsable hierarchy is in the Description section; every concept is documented in the cross-reference section (named individuals). Download: ffonto-vocab.ttl.
